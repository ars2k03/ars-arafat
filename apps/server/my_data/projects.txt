Projects

1. WA Gateway
   - Tagline: WhatsApp OTP API
   - Duration: October 2026 – November 2026
   - Description: Self-hosted WhatsApp OTP gateway: link your number, create an API key and send verification codes with one HTTP request.
   - Features:
     - Developers can send WhatsApp OTPs via API after QR pairing, with auto-reconnect and Redis-backed sessions
     - Dashboard for API keys, custom OTP templates, live playground, message logs and daily/monthly usage limits
   - Tech Stack: Next.js, NestJS, TypeScript, PostgreSQL, Redis
   - Live Site: https://wa.ars2k03.tech
   - API Docs: https://wa.ars2k03.tech/docs
   - Source Code: https://github.com/ars2k03/wa
   - Role: Full-stack developer (built and maintained)
